# PRISM Steam Trailer v2

`prism-steam-trailer-v2.mp4` is a 60-second, 1920x1080 H.264/AAC trailer candidate assembled from the existing PRISM capture set and the PRISM ethereal music loop.

This cut adds gentle camera movement, fades, readable caption cards, and a consistent 16:9 frame. It is a stronger upload candidate than the earlier still-image draft, but it still uses staged captures rather than a continuous screen recording. Replace individual shots with live recordings later if a final marketing pass needs more interaction detail.

Rebuild from the repository root with:

```bash
npm run steam:trailer:build
```

The original draft remains at `output/steam-trailer-draft/` for comparison. `contact-sheet.png` is a quick visual review of the v2 timeline.
