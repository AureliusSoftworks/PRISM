## 0) Before you open Prism (desk setup)

Do these once:

1. Plug in power (laptops throttle and fans get loud on battery).
2. Close Slack, email, browsers with noisy tabs, anything that can toast.
3. Turn on Focus / Do Not Disturb (macOS Focus or Windows Focus Assist).
4. Set display to a normal resolution you will not change mid-day (aim 1080p or 1440p recording).
5. Create a capture folder:

```text
captures/steam-trailer-YYYY-MM-DD/
  01-atm-open/
  02-companion-turn/
  03-zen-calm/
  04-signal-hit/
  05-sandbox-glance/
  06-coffee-setup/
  07-coffee-live/
  08-debate-broll/
  09-local-privacy/
  10-brand-pack/
```

6. Open your screen recorder and confirm:
   - Mic muted (we add music later)
   - System audio off unless you deliberately want UI sounds
   - Saving into that folder

## 1) Open Prism in “demo costume”

We want Prism to look finished and private — like a movie set, not your real desk.

| Setting | Choose |
|---|---|
| Theme | **Dark** |
| Lane | Prefer **LOCAL** for most takes (matches the sanctum story) |
| Zoom / UI scale | Fixed — do not change between shots |
| Account | A **demo** account/profile if you have one; otherwise scrub personal threads off screen |
| Content | Demo bots only; no real private chats |

Quick visual sweep before any recording:
- No error toasts
- No “connecting…” hung states
- No unfinished tutorial callouts you don’t want in the trailer
- Cursor size normal

## 2) Stage the scenes (before hitting record)

Prep each room so the take is acting, not setup.

### Hook (`01-atm-open`)
- Land on **Home / living shell** with a strong atmosphere.
- Know the one intentional move you’ll make (click a mode, start typing, or move to Chat).

### Companion (`02-companion-turn`)
- Open Chat / companion.
- Have these lines ready (type them live, or paste carefully so it still feels human):

**You:** `I'm back. Keep me honest today.`

**Companion (ideal reply vibe):** welcome-back + clear + wonder  
If the live reply is ugly, re-roll once. Ugly text kills this beat.

### Spectrum (`03`–`05`)
- Bookmark or remember how to open **Zen**, **Signal**, **Sandbox** fast.
- For each: find one pretty still frame *before* recording so you’re not hunting.

### Interplay (`06`–`07`, backup `08`)
- In **Coffee**, pre-seat 3–4 distinct bots.
- Know where **Start session** is.
- Optional: have a Debate scene ready as backup only.

### Local (`09`)
- Know exactly where the **LOCAL | ONLINE** control is.
- Practice once: end on LOCAL looking intentional (not frantic toggling).

### Close (`10`)
- Export or locate:
  - `apps/web/public/refraction-emblem.svg`
  - `apps/web/public/wordmark.svg`
- Or capture a clean end card later in the editor from those assets.

---

## 3) Recording order (recommended)

Do emotional / fragile takes while fresh:

1. `01-atm-open` — Hook
2. `02-companion-turn` — Companion
3. `06-coffee-setup` + `07-coffee-live` — Interplay
4. `03-zen-calm`, `04-signal-hit`, `05-sandbox-glance` — Spectrum
5. `09-local-privacy` — Local
6. `08-debate-broll` — only if Coffee live failed
7. `10-brand-pack` — last (stills are fine)

For each shot:
- Record **separate files**
- Do **2 takes** of Hook, Companion, Coffee live
- Stop if a toast appears — re-take
- Keep the mouse calm; pause a beat after important clicks
