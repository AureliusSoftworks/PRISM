# Steam Content Survey: AI Disclosure Draft

Status: draft for human review before Steamworks submission.

Steam's [Content Survey](https://partner.steamgames.com/doc/gettingstarted/contentsurvey?l=french&language=english)
separates pre-generated AI content from content generated while the game is
running. PRISM should be described from the shipped Steam build, not from
development-only features.

## Recommended classification

### Live-generated content

Yes. Prism Desktop can generate dialogue during use. The default Steam path
uses packaged local models; a player may explicitly enable an online provider
and supply or configure the provider access required for that choice. The
generated dialogue can be presented as text and, where enabled, rendered as
bot speech during play.

### Pre-generated content

The current Steam ledger (`steam-asset-rights-ledger.json`) classifies this
category as present. Select this category only after reviewing the ledger and
the matching report from the exact submitted build. The Marketplace allowlist
and `STEAM_CONTENT_REPORT.md` establish which bundles are packaged, but they
do not by themselves establish how every asset was created.

## Reviewer-facing live-generation description

> PRISM is a local-first desktop AI workspace with interactive bot dialogue.
> During play, dialogue may be generated by packaged local models. Players can
> optionally enable an online provider and use their own provider credentials;
> that choice is not required for the default local experience. Generated
> dialogue may be displayed as text and rendered as bot speech. PRISM does not
> intentionally imitate celebrities, historical recordings, actors, or other
> recognizable real people. Player-imported reference voices require the
> player's consent and ownership, remain local and encrypted, are excluded from
> Marketplace and export paths, and can be deleted.

## Guardrail facts to disclose accurately

- `LOCAL` mode is a hard privacy boundary: provider, research, premium voice,
  and other network-backed capabilities are blocked rather than silently
  escalated.
- Steam staging is fail-closed for Marketplace content. The current release
  report contains 25 approved bundles; entries with unresolved rights or
  provenance remain development-only.
- Image generation has a safety recovery path. A provider refusal can trigger
  one general-audience rewrite that removes explicit, graphic, hateful,
  exploitative, branded, franchise-specific, artist-specific, or real-person
  likeness details; if the safe retry is refused, the image is not produced.
- The shipped voice path uses the qualified Instant/Kokoro assets by default.
  Voice+ remains gated until its separate cross-platform qualification is
  complete.
- The product currently does **not** claim that a universal moderation service
  filters every arbitrary text response from every local or user-selected
  provider. Provider behavior, model behavior, and user-authored prompts can
  vary. This is an internal release checkpoint, not wording to omit from the
  Steam review decision.

## Human release checkpoint

Before answering the Steam Content Survey:

1. Confirm whether any shipped store, trailer, Marketplace, or bundled runtime
   artwork was created with generative tools, using the rights/provenance
   ledger.
2. Decide whether the current provider/prompt boundaries are sufficient for
   the live-generated-content guardrail question. If Steam review requires a
   universal text moderation layer, implement and test that layer before
   submission; do not represent the current build as having one.
3. Verify that store copy names live-generated dialogue, optional online
   providers, local default behavior, and voice limitations consistently.
4. Record the final answers and exact build number in the Steam launch Bead.
