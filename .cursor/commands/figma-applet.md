# /figma-applet — PRISM applet Figma mockups

Create or polish a PRISM applet screen in Figma so it matches the **live app** (Dark + Light twins).

## Do this

1. Read and follow `.cursor/skills/_prism-figma-applet/SKILL.md`.
2. For shared navbar glyphs, brand lockup, or applet-specific pointers, open `reference.md` beside that skill.
3. Work CSS-faithful against `apps/web` sources and `apps/web/public` sprites — no invented chrome.
4. Always ship **Dark and Light** together, shelf assets off-canvas, and screenshot-validate both before asking for 🟢/🟡/🔴.

## If I name an applet / state

Use that (e.g. “Signal live session”). Otherwise ask which applet + state before drawing.

## Examples

- `/figma-applet` → Signal live session view  
- `/figma-applet` → Coffee Live general view polish  
- `/figma-applet` → Coffee Group Setup Dark+Light  
- `/figma-applet` → Debate gallery Dark+Light

## Lessons already baked into the skill

Group Setup taught durable rules (white AutoLayout fills on Dark, state ≠ Live clone, roster glyph circles, widen gutters). Those live in `_prism-figma-applet` — don’t re-learn them from scratch.
